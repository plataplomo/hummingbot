
# Rule: Report Structure Findings Clearly

**Mandate:** Present the generated code skeletons and Mermaid diagrams in a clean, organized Markdown format. Clearly label each section and ensure the output directly addresses the prompt's request.

**Guidelines:**
- **File Structure:** Generate separate Markdown files for significant components or scopes as requested.
- **Code Blocks:** Use fenced code blocks with Python syntax highlighting for code skeletons.
- **Diagram Blocks:** Use fenced code blocks with `mermaid` language specifier for diagrams.
- **Labels:** Clearly label which class/file each skeleton or diagram corresponds to.
- **Conciseness:** Present only the requested mapping information (skeletons, diagrams). Avoid adding extraneous commentary or analysis of the implementation logic itself.
- **Verification:** Briefly state that the skeletons/diagrams accurately reflect the structure found in the source code for the given scope.
