**Objective:** CRITICAL REFACTOR - Align `HyperliquidEip712Authenticator` with Hyperliquid SDK's `sign_l1_action` Scheme for `/exchange` Endpoint Authentication.

**Context & Rationale:**
Our current `HyperliquidEip712Authenticator` for Hyperliquid is not correctly signing requests for the `/exchange` endpoint (e.g., placing orders, cancelling orders). The Hyperliquid Python SDK uses a specific scheme often referred to as `sign_l1_action` for these. This involves:
1.  `msgpack`ing the core `action` payload (e.g., `{"type": "order", "orders": [...]}`).
2.  Hashing this `msgpack`ed action along with a millisecond `nonce`, `vaultAddress` (usually `None` for user trades), and `expires_after` (usually `None`) using `keccak` to produce an `action_hash`.
3.  This `action_hash` becomes the `connectionId` in a simple "Agent" EIP-712 message: `{"source": "a", "connectionId": action_hash_bytes}`.
4.  This "Agent" message is then EIP-712 signed against a domain with `name: "Exchange"`.
5.  The final HTTP POST request to `/exchange` has a JSON body containing the original `action`, the `nonce` used, and the EIP-712 `signature` (`r`, `s`, `v`).
6.  Crucially, **no** `X-HL-Timestamp`, `X-HL-Nonce`, or `X-HL-Signature` headers are used for these `/exchange` action requests.

Our current implementation incorrectly tries to put the nonce and signature in headers and signs a different EIP-712 message structure for `/exchange`. This refactor will align us with the SDK's verified method, fixing critical authentication failures.

We will modify the *single existing* `HyperliquidEip712Authenticator`. The `prepare_request` method will need to differentiate logic based on the request `path`. For now, we will only implement the correct logic for `path == "/exchange"`. Other paths will raise a `NotImplementedError` or `APIError` until their specific signing schemes (if any) are implemented.

*   **Step 2.4: Refactor `prepare_request` Method**
    *   This method must now implement conditional logic based on the `path`.
    *   **If `path == "/exchange"`:**
        1.  **Input Validation:**
            *   Ensure `data` is a dictionary (the action payload). If not, raise `ValueError`.
            *   Ensure `self._account` is not `None`.
        2.  **Prepare Action Payload:**
            *   `action_payload_dict: dict[str, Any] = dict(data)` (make a mutable copy).
            *   Call `self._clean_order_type_fields(action_payload_dict)` to remove nulls from order types.
            *   **Address Lowercasing:** Iterate through `action_payload_dict`. If any value is an Ethereum address string (heuristic: `startswith("0x")` and length 42), convert it to lowercase. This is critical for consistent hashing.
        3.  **Generate Nonce:**
            *   `current_nonce_ms: int = await self._get_next_nonce_ms()`
        4.  **Define `vault_address_for_hash` and `expires_after_for_hash`:**
            *   For standard user trades (non-vault), `vault_address_for_hash: str | None = None`.
            *   `expires_after_for_hash: int | None = None`.
        5.  **Calculate `action_hash` (mimicking SDK's `action_hash` function):**
            *   `msgpacked_action: bytes = msgpack.packb(action_payload_dict)`
            *   Initialize `action_hash_data_parts: list[bytes] = [msgpacked_action]`
            *   `action_hash_data_parts.append(current_nonce_ms.to_bytes(8, "big"))`
            *   If `vault_address_for_hash` is not `None`:
                *   `action_hash_data_parts.append(b"\x01")`
                *   `action_hash_data_parts.append(address_to_bytes(vault_address_for_hash))`
            *   Else (vault_address_for_hash is `None`):
                *   `action_hash_data_parts.append(b"\x00")`
            *   If `expires_after_for_hash` is not `None`:
                *   `action_hash_data_parts.append(b"\x00")` # Note: SDK uses one b"\x00" if vault is None AND expires_after is None. This needs care.
                                                            # The SDK logic for expires_after is: if expires_after is not None: data += b"\x00"; data += ...
                                                            # This implies if expires_after is None, nothing more is added for it.
                *   `action_hash_data_parts.append(expires_after_for_hash.to_bytes(8, "big"))`

            *   `action_hash_input_bytes: bytes = b"".join(action_hash_data_parts)`
            *   `action_hash_bytes: bytes = keccak(action_hash_input_bytes)`
        6.  **Construct `phantom_agent_message` (for EIP-712):**
            *   `source_char: str = "a"` (Assuming mainnet. TODO: Make configurable if testnet "b" is needed).
            *   `phantom_agent_message: dict[str, Any] = {"source": source_char, "connectionId": action_hash_bytes}`
        7.  **Construct `structured_data_to_sign` for EIP-712:**
            ```python
            structured_data_to_sign = {
                "domain": self._exchange_action_domain.model_dump(by_alias=True),
                "message": phantom_agent_message,
                "primaryType": "Agent",
                "types": self._exchange_action_agent_types.model_dump(by_alias=True),
            }
            ```
        8.  **Sign the Message:**
            *   `signable_message = encode_typed_data(full_message=structured_data_to_sign)`
            *   `signed_message_obj = self._account.sign_message(signable_message)`
            *   `signature_dict: dict[str, Any] = {"r": to_hex(signed_message_obj.r), "s": to_hex(signed_message_obj.s), "v": signed_message_obj.v}`
        9.  **Construct Final HTTP JSON Body:**
            ```python
            final_http_body: dict[str, Any] = {
                "action": action_payload_dict, # The cleaned, address-lowercased action
                "nonce": current_nonce_ms,
                "signature": signature_dict,
            }
            if vault_address_for_hash: # Only include if set
                final_http_body["vaultAddress"] = vault_address_for_hash
            ```
        10. **Prepare HTTP Headers:**
            *   `final_headers: dict[str, str] = {"Content-Type": "application/json"}`
            *   If `headers` arg was passed to `prepare_request`, merge any non-Content-Type headers.
        11. **Return `AuthenticatedRequestComponents`:**
            *   `headers=final_headers` (NO `X-HL-*` auth headers).
            *   `params=params` (passed through).
            *   `data=final_http_body`.
    *   **Else (if `path != "/exchange"`):**
        *   Log an error or warning.
        *   Raise `NotImplementedError(f"Signing for path {path} is not implemented.")` or an `APIError` indicating this. This ensures we don't accidentally use the wrong signing scheme.
