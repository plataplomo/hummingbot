**Objective:** CRITICAL FIX - Implement Nonce in Signed Agent Message for Hyperliquid EIP-712 Authentication.

**Context & Rationale:**
Our current Hyperliquid EIP-712 Agent signature implementation for the `/exchange` endpoint does not include the `nonce` (millisecond timestamp) within the EIP-712 signed message payload. Instead, it's sent as a separate `X-HL-Nonce` header, and `X-HL-Timestamp` uses wall-clock time.

The official Hyperliquid Python SDK, which is the authoritative reference for signing, includes the `nonce` directly in the `message` part of the EIP-712 `Agent` type that gets signed. The `X-HL-Timestamp` header then mirrors this signed nonce value. This is crucial for security and preventing replay attacks as intended by Hyperliquid.

This fix aligns our implementation with the SDK, addressing a primary cause of signature validation failures (e.g., "User does not exist" errors due to incorrect signer recovery).
